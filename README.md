# 🪔 Diwali Sales Analysis using Python

## 📌 Project Overview
This project analyzes Diwali sales data to understand customer purchasing behavior and sales trends during the festive season.  
Using Python and data analysis libraries, the project uncovers insights related to demographics, product categories, and regional sales performance.

---

## 🎯 Objectives
- Clean and preprocess Diwali sales data
- Perform exploratory data analysis (EDA)
- Analyze customer demographics and buying patterns
- Identify top-performing products and categories
- Generate actionable business insights

---

## 🗂️ Dataset Information
The dataset contains Diwali sales transactions with the following attributes:
- User ID
- Gender
- Age Group
- Marital Status
- State
- Occupation
- Product Category
- Orders
- Amount Spent

**File Used:**  
- `Diwali Sales Data.csv`

---

## 🛠️ Tools & Technologies
- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Jupyter Notebook**

---

## 🔍 Steps Performed
1. Data loading and inspection
2. Data cleaning (handling null values, data type correction)
3. Exploratory Data Analysis (EDA)
4. Visualization of key metrics
5. Business insight generation

---

## 📊 Key Analysis & Insights
- Female customers contributed higher purchase amounts compared to males
- Age group 26–35 showed the highest purchasing power
- Married customers made more purchases
- Top sales came from states like Uttar Pradesh, Maharashtra, and Karnataka
- IT, Healthcare, and Aviation professionals were major contributors
- Food, Clothing, and Electronics were top-selling categories
